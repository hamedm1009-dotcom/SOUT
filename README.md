# SOUT | صوت

تطبيق PWA للتفريغ النصي المباشر (HTML/CSS/JS Vanilla فقط).

## التشغيل محليًا
الميكروفون وService Worker يحتاجان `localhost` أو HTTPS:
```
cd sout
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080` في Chrome أو Edge.

## النشر المجاني على GitHub Pages
1. أنشئ مستودعًا على GitHub وارفع محتوى مجلد `sout` في الجذر.
2. Settings ← Pages ← Source: `Deploy from a branch` ← `main` / `(root)`.
3. افتح الرابط `https://USERNAME.github.io/REPO/` (HTTPS تلقائيًا) ثم «تثبيت التطبيق» من المتصفح.
كل المسارات نسبية فتعمل داخل مجلد المستودع.

## قيود Web Speech API (مهم)
- أفضل دعم في Chrome/Edge (سطح المكتب وأندرويد)؛ Safari دعمه جزئي؛ Firefox غير مدعوم غالبًا.
- يحتاج إنترنت في Chrome لأن الصوت يُعالج على خادم Google.
- عند تفعيل «تسجيل الصوت كملف» قد يتعارض الميكروفون مع التعرّف على بعض هواتف أندرويد؛ إن توقف التعرّف عطّل الخيار.
- لا يدعم تمييز المتحدثين تلقائيًا: التسمية يدوية لكل فقرة.
- لا يوجد «تحديد اللغة تلقائيًا» لأن المحرك الأصلي لا يدعمه، فلم أعرضه.
- يتوقف التعرّف عند قفل الشاشة أو إخفاء التبويب في أغلب الهواتف بسبب إدارة الطاقة. أبقِ الشاشة مضاءة.
- دقة اللهجة المصرية (`ar-EG`) والتقاط الصوت من مسافة تعتمدان على المحرك والميكروفون والضوضاء، ولم تُختبر هنا على أجهزة فعلية.
- أيقونة SVG تكفي لأندرويد؛ لأيقونة iOS أضف PNG بحجم 180×180 و512×512 وحدّث `manifest.json`.

## الترقية إلى محرك أدق
واجهة `Transcriber` في `js/transcription.js` (`start/pause/resume/stop` + callbacks `final/interim/error`). أنشئ صنفًا مماثلًا يرسل مقاطع MediaRecorder إلى Backend خاص بك (Cloudflare Worker أو Node) يستدعي Whisper أو Google STT أو Deepgram (يدعم Diarization) ويحتفظ بمفتاح API في الخادم فقط. ستكون هناك تكاليف حسب الاستهلاك، وعليك إعلام المستخدم بأن الصوت يُرسل لتلك الخدمة.
